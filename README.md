# 🎵 Music Assistant (iOS Edition)

Native iOS Client für **Music Assistant 2.0** mit KI-DJ, Live-Karaoke Lyrics, Apple Dynamic Island, Apple Watch Fernbedienung und Multiroom-Wiedergabe (Sonos, AirPlay, Chromecast).

---

## 📲 Installation via SideStore & AltStore

Du kannst die App direkt über **SideStore** oder **AltStore** auf deinem iPhone installieren und automatisch aktuell halten.

### Methode 1: SideStore Source hinzufügen (Empfohlen)
Füge die offizielle Source in SideStore hinzu, um automatische Updates und Ein-Klick-Installationen zu erhalten:

1. Öffne **SideStore** auf deinem iPhone.
2. Gehe auf den Tab **Sources** (unten) und tippe oben rechts auf das **`+`**-Symbol.
3. Füge folgende URL ein:
   ```text
   https://raw.githubusercontent.com/LegoPuck-orginal/music-assistant-app/main/altstore-source.json
   ```
4. Tippe auf **Add**. Die App *Music Assistant (iOS Edition)* erscheint nun direkt in deiner SideStore-Bibliothek mit Update-Hinweisen und Installations-Button!

> **Tipp (1-Klick-Link auf dem iPhone):**
> [📲 In SideStore als Source öffnen](sidestore://source?url=https%3A%2F%2Fraw.githubusercontent.com%2FLegoPuck-orginal%2Fmusic-assistant-app%2Fmain%2Faltstore-source.json)  
> [📲 In AltStore als Source öffnen](altstore://source?url=https%3A%2F%2Fraw.githubusercontent.com%2FLegoPuck-orginal%2Fmusic-assistant-app%2Fmain%2Faltstore-source.json)

## 🔒 Wichtiger Hinweis bei privaten GitHub Repositories
Damit SideStore oder Safari die Source-JSON und die IPA ohne Authentifizierungsfehler (404) herunterladen kann:
- Das GitHub-Repository `LegoPuck-orginal/music-assistant-app` muss auf **Public** gestellt sein (oder du lädst die IPA aus den Releases im Browser herunter und teilst sie an SideStore).
- Da bereits alle persönlichen Tokens, IPs und Zugangsdaten bereinigt wurden, kann das Repo bedenkenlos öffentlich geteilt werden.

- 🏝️ **Native Apple Dynamic Island**: Animierte Visualizer-Wellen und Now Playing Cover
